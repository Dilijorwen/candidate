# Постобработка OCR паспорта РФ

**Задача.** Принимать документы с правильными значениями всех десяти полей, минимизируя ошибочные принятия.

**Метод.** Нормализация текста, сопоставление VIZ и MRZ, восстановление отсутствующих реквизитов из MRZ, проверки дат, возраста и полноты строк. Справочник подразделений используется как признак. Логистическая регрессия оценивает совместную правильность полей по 138 признакам. Финальная модель обучена на 2400 документах, 600 использованы для выбора порога 0.995. Разрешён источник `mobile`; применение работает на CPU без интернета и внешних библиотек.

**Основные наблюдения.** Исходный OCR полностью верен в 1680 из 3000 документов (56%). Чаще ошибаются орган выдачи и место рождения. Высокий confidence и совпадение ФИО в VIZ/MRZ встречаются при ошибках. Исправление названий по ближайшей записи справочника улучшило 10 значений, но испортило 259, поэтому автоматическая подстановка отклонена.

**Проверка.** Первоначальная модель дала 2 ошибки среди 29 принятых документов на holdout. После усиления проверок вложенная кросс-валидация на пяти групповых фолдах дала 246 accept и 3 ошибки. Для `mobile` — 102 accept без наблюдаемых ошибок. Ограничение источника выбрано после просмотра CV, поэтому этот результат не является независимой оценкой финальной политики.

**Результат и прогноз для test:**

| Показатель | Значение |
|---|---:|
| Документов | 2000 |
| Принято / отклонено | 105 / 1895 |
| Покрытие | 5.25% |
| Ожидаемое число ошибочных accept | 0.51 |
| Условный 95% прогнозный интервал ошибок | 0–3 |

Прогноз рассчитан по модели Jeffreys Beta(0.5,0.5): 105 × 0.5 / 103. Он предполагает переносимость риска внутри `mobile`. Выбор источника после CV, адаптация метода к датасету и зависимость результатов фолдов ограничивают надёжность оценки. Для подтверждения финальной политики нужен отдельный внешний holdout.
